# TallyWhatsApp — TallyPrime & Tally ERP 9 WhatsApp Integration (v1.0.40)

TallyWhatsApp is a Windows desktop application and lightweight TDL integration that connects **TallyPrime** and **Tally ERP 9** with WhatsApp for GST invoice PDF sharing, automated payment reminders, and party ledger statements—without Meta WhatsApp Business API onboarding or per-message wallet charges.

## Key Features

- Automatic GST invoice PDF attachment & WhatsApp sharing
- Payment reminders with outstanding balances & configurable pacing
- Party ledger statements, receipts, and credit/debit note dispatch
- Custom English, Hindi, and Hinglish message templates
- Multiple WhatsApp profiles per company
- Local Windows-based operation (company data stays on your PC)
- Silver Single-PC and Gold Multi-PC LAN Hub & Spoke editions

## System Requirements

- **OS:** Windows 10 or Windows 11 (x64)
- **Accounting Software:** TallyPrime (all versions) or Tally ERP 9
- **WhatsApp:** Active personal or business WhatsApp account (paired via QR code)
